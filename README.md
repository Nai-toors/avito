# Avito Moderation Dashboard

Веб-приложение для модерации объявлений и просмотра статистики. Реализован полный цикл работы модератора: просмотр списка, фильтрация, детальный просмотр и принятие решений.

## Запуск проекта

Можно запустить через Docker Compose или локально.

### Через Docker

```bash
# Сборка и запуск контейнеров (клиент + сервер)
docker-compose up --build
```

Приложение будет доступно по адресу: http://localhost:8080

### Локальный запуск (Dev mode)

Если вы хотите запустить проект без Docker:

#### 1. Сервер

```bash
cd server
npm install
npm start
# API запустится на http://localhost:3001
```

#### 2. Клиент

```bash
cd client
npm install
npm run dev
# UI запустится на http://localhost:5173
```

## 🛠 Стек технологий

- **Core:** React 18, TypeScript, Vite
- **Network & State:** TanStack Query (React Query), Axios
- **UI Framework:** Material UI (MUI v6)
- **Data Visualization:** Recharts
- **Tests:** Vitest, React Testing Library
- **Infrastructure:** Docker, Nginx

## Реализованный функционал

Проект выполняет все обязательные требования и все дополнительные задания (со звёздочкой).

### Основные возможности

- **Список объявлений:** Пагинация, сортировка (по цене, дате), отображение статусов.
- **Фильтрация:** Поиск по тексту, фильтры по категории, цене и статусу.
- **Детальный просмотр:** Галерея изображений, информация о продавце, история модерации.
- **Решения:** Одобрение, отклонение (с выбором причины) и отправка на доработку.
- **Статистика:** Графики активности и KPI модератора.

### Дополнительные возможности (Bonus)

- **Темная тема:** Поддержка переключения тем с сохранением выбора в localStorage.
- **Горячие клавиши:**
  - `A` — Одобрить
  - `D` — Отклонить
  - `←` / `→` — Навигация между объявлениями
  - `/` — Фокус на поиск
  - `Esc` — Вернуться к списку
- **Bulk-операции:** Множественный выбор объявлений для массового одобрения или отклонения.
- **Синхронизация URL:** Все параметры фильтрации и пагинации сохраняются в адресной строке.
- **Экспорт данных:** Возможность скачать статистику в CSV и PDF.
- **Real-time обновления:** Автоматическое обновление списка объявлений.
- **Docker-среда:** Полная контейнеризация Frontend (Nginx) и Backend.
- **Отмена запросов:** Прерывание лишних HTTP-запросов при навигации.
